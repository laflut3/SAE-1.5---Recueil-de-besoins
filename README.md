# SAE-1.5---Recueil-de-besoins
Dans cette SAE, divisé en 3 livrables, et fait en groupe de 3/4 personnes, nous avons dû :  
- créer le script d’une Escape Game et l’imager dans le livrable 1.
- Nous avons créé à partir de l’Escape Game d’un autre groupe un site web et imaginé les différentes salles pour le livrable 2.
- Enfin nous avons dû noter l’Escape Game du groupe qui a concrétisé notre projet pour le livrable 3
